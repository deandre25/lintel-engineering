# Credits

Third-party assets used in this project, with their licences.

## Typefaces

Both faces are downloaded at build time by `next/font` and served from this
origin. No request is made to a font CDN at runtime.

| Typeface                                                               | Role                 | Designer                          | Licence                                                   |
| ---------------------------------------------------------------------- | -------------------- | --------------------------------- | --------------------------------------------------------- |
| [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) | Display and headings | Rodrigo Fuenzalida, Jordan Egstad | [SIL Open Font License 1.1](https://openfontlicense.org/) |
| [Hanken Grotesk](https://fonts.google.com/specimen/Hanken+Grotesk)     | Body and interface   | Alfredo Marco Pradil              | [SIL Open Font License 1.1](https://openfontlicense.org/) |

## Imagery

None. Every graphic on this site is an inline SVG component written for this
project and lives in `src/components/graphics/`. There are no stock photographs
and no icon library.

If a photographic texture is introduced later, the photographer, source and
licence will be recorded here before the image is committed.
